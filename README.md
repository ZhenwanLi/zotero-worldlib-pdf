# 世图 PDF 助手（开发测试版）

## 状态

本项目是从已安装的 0.1.5 插件提取并修改的独立副本。原插件的来源与再分发授权尚待确认；在确认授权之前，不应公开再分发源码、图标或安装包，也不应将其声明为已获授权的开源项目。

当前源码包含尚未打包的安全修改。旧的 0.1.6／0.1.7 XPI 已从项目中移除，不应作为本次修复的发布包。

## 修改

- 优先查询文献管理页的 `getpersondoc_new` 接口，仅默认读取近 24 h 数据，不再每次拉取历史。
- 已完成且链接有效则直接下载；待应助／应助中则关联已有任务并等待，不重复提交。
- 近 24 h 无匹配且本地没有提交记录时，沿用原 `zixun_sendmsg` 接口提交。
- 本地已有提交记录、但近 24 h 找不到的任务，才补查历史；未查到也不自动重新提交。
- 空响应、格式异常及网络错误不能视为没有记录。历史补查失败时保留近期已匹配结果，但禁止新增提交。
- 将 `title`、`status`、`url` 转换为原任务引擎可识别的记录，保留严格 DOI 匹配。
- 默认流程不再依赖原消息历史分页，避免分页异常阻塞已有结果下载。
- 完成状态仅接受“应助完成”；超过网站规定的 24 小时有效期或时间无法核实的链接不自动下载。
- 查询结果格式异常时停止处理，不能将接口异常当作无结果后自动重新提交。
- 支持登录后停留在 `result_query.aspx`。

## 验证

```sh
node --test tests/site.test.js
```

本地测试使用合成账号、任务与下载链接，不需要真实登录，不会向网站提交需求。覆盖近期结果复用、防重复提交、查询异常、缓存处理与隐私保护等分支。测试数量与结果以实际命令输出为准。

源码修改后的 Zotero 运行环境端到端验证仍待完成，不应将本地测试通过等同于真实下载流程已通过验证。

## 隐私与下载安全

- 账号信息用于网站认证，登录 Cookie 保存在 Zotero 使用的 Cookie 存储中；插件会将网站的相关会话 Cookie 延长保存至最多 30 天。
- 本地任务包含文献标题、DOI、文献库条目标识、账号指纹与任务状态，属于个人使用数据，不应上传 GitHub 或附在公开 issue 中。
- 下载链接仅在内存中使用，不写入新的任务快照。旧任务文件的备份仍可能包含历史链接与账号参数；本次修改不会自动删除已有文件，请勿公开这些备份。
- 删除列表记录是隐藏记录而非彻底擦除，保留的去重元数据仍属于个人数据。
- 自动下载仅允许代码中明确列出的 HTTPS 主机与默认端口；其他主机需要先核实再调整名单。底层下载器的跨域重定向约束尚未完成验证，不能视为完整的内网请求防护。
- 分享前检查实际待提交文件，不要仅依赖 `.gitignore`。不要分享 Cookie、任务文件、日志、带账号参数的链接或下载的 PDF。

## 安装与回退

安装前保留原版 XPI，并备份 Zotero 数据目录中的 `worldlib-pdf` 任务文件。通过 Zotero 插件管理器“从文件安装插件”选择经过验证的发布包；不要将目录中的旧包误认为已包含当前修复。

如需回退，可从文件安装事先备份的原版包。不要删除任务文件或 PDF 附件。
